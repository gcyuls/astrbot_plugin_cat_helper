# astrbot_plugin_cat_helper

呆猫群聊管家与怪物猎人助手（AstrBot 插件）

## 功能特性

1. **怪物猎人 12 位集会码自动录入**：智能识别群内发布的 12 位怪猎集会码并自动保存发布人与时间。
2. **集会码查询**：发送 `码来` 即可分段获取最新集会码信息，方便长按复制。
3. **今天玩什么（武器抽卡）**：发送 `今天玩什么`，随机抽取 14 种怪猎武器之一，包含高清武器图标与个人冷却防刷保护。
4. **人类本质复读机**：
   - 经典词头（啊啊/唉/并非/看看）、词尾（导致的）及特定正则（叠词等）原样带零宽空格复读；
   - **智能渐进式复读打断**：单群隔离追踪，允许少量自然复读，随后按梯度增加插嘴打断概率，触发后发送 `{消息}喵`。
5. **私聊传话（Cosplay）**：好友向机器人发送私聊，机器人自动转发至设定的目标群聊。
6. **多用户关键词私聊提醒（Reminder）**：在群内检测到关键词时，主动私聊通知对应的成员 QQ，支持多用户独立规则、同消息多词去重及自提及过滤。
7. **每日定时维护**：每日凌晨定时清空过期集会码与冷却历史。

## 配置项说明

本插件已适配 AstrBot 官方 WebUI 配置面板，可在管理后台直接修改以下设置：

- `cosplay_target_group`：私聊传话的目标群号（填入你的实际目标群号）。
- `weapon_cooldown_seconds`：抽卡防刷冷却时间（默认 60 秒）。
- `clean_hour`：每日数据定时清空时间点（默认凌晨 4 点）。
- `repeat_allow_count`：打断复读前允许的安全复读条数（默认 2）。
- `repeat_base_prob`：起步打断概率（默认 0.25）。
- `repeat_prob_step`：随后每条复读的概率增量（默认 0.25）。
- `repeat_max_count`：强制 100% 打断的最大复读条数（默认 6）。
- `repeat_interrupt_suffix`：打断追加的后缀（默认 `喵`）。
- `reminder_rules`：多用户提醒规则列表（配置目标 QQ、关键词列表、备注名称）。

## 安装方式

1. **WebUI 上传**：在 AstrBot WebUI -> 插件管理 -> 点击「安装插件」 -> 上传 `astrbot_plugin_cat_helper.zip`。
2. **手动安装**：将解压后的 `astrbot_plugin_cat_helper` 文件夹放置在 AstrBot 的 `data/plugins/` 目录下，在 WebUI 中重载插件。
